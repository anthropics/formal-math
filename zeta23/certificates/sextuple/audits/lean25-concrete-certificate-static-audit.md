### F4 (None): decoders are not load-bearing; no silent out-of-range mapping (Question 3)
- `concreteLeafCheck_sound` (`TreeReader.lean:93-96`) is `∀ box payload, concreteLeafCheck box payload = true -> BoxPredicate (affineEnergyGoal (1/80) (1094977/5000000000)) box`, via `affineLeafCheck_sound` (`AffineTree.lean:849-862`), which quantifies over every `payload : AffineLeafPayload α`. `checkAffineCertificate_sound` (`AffineTree.lean:865-875`) quantifies over arbitrary `payloads : CursorStream (AffineLeafPayload α)`. So soundness holds for *every* payload the stream could hand to the checker, however it was decoded; a wrong decoder can only make the replay fail, never make it accept something unsound.
- `decodeTermRef` (`TreeReader.lean:39-43`): `code < 56` -> piece; `65535` -> zero; `32768 ≤ code ∧ code - 32768 < 871` -> scalar; everything else (`56..32767`, `33639..65534`) -> `none`. The `Fin` proofs are the branch hypotheses, so no index can be out of range.
- `leafTerm` (`TreeReader.lean:46-47`) uses `getD .zero`, but `decodeLeafWord` (`TreeReader.lean:57-61`) only returns a quadratic payload when `leafTermsValid w = true` (`TreeReader.lean:50-51`, all fifteen codes decode). If a code is undecodable, the payload is `none`, and `replayAffineTree` returns `none` on `payloads.get? = none` (`AffineTree.lean:737-738`), so the whole certificate fails. Even in the hypothetical that the `.zero` placeholder were used, `zeroRankModel` is itself a sound lower model (value `0 ≤ 2·mtKernel²`, `ScalarAdapter.lean:251-255`).
- `leafAnchor` (`TreeReader.lean:54`) reads five 16-bit fields; values above `16384` are rejected by `RelativeAnchor.check 16384` inside `relativeRankTangentCheck` (`AffineTree.lean:964-965, 990-994`). Independent decode: maximum anchor code in the data is exactly `16384` (allowed, `≤`).
- Kind bit: `w = 0` -> `.tail`; `w` odd -> quadratic; `w` even and nonzero -> `none` (`TreeReader.lean:58-61`). The `w < 2 ^ leafWordBits` guard is redundant with the mask in `leafWordRead` (`TreeReader.lean:67`); harmless.
